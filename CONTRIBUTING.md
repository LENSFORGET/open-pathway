# Contributing

Use Node.js 22+, run `npm ci`, and start the app with `npm run dev`.

Keep changes focused and include a short explanation of the behavior they improve. Add meaningful tests for changes to branching, validation, persistence, or scoring. Run `npm run check` before submitting a pull request, and manually check affected flows with keyboard navigation and a narrow screen.

Keep Traditional Chinese and English text in sync. Use only fictional, non-identifying examples. Do not contribute credentials, personal data, customer materials, deployment account IDs, screenshots of private systems, or assets you cannot license.

New original contributions are submitted under the repository MIT license. Document third-party sources and licenses in `THIRD_PARTY_NOTICES.md`.
